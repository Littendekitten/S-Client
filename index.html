    Your private mod library is empty

    Import one or more .sclient files, or a ZIP containing mods and shader packs. Nothing is preinstalled or publicly downloadable. Community mods use the sandboxed SCL language.

    ⌘

    Your library, your files

    S-Client does not publish a public mod catalogue. You can export only mods already present in your own library. SCL source is validated by the client and runs in a sandboxed command interpreter; uploaded JavaScript is never executed.

    BATCH IMPORT

    1. Every mod must declare "gameVersion": "1.0". Mods without it, or for an unsupported version, are refused.
    2. Select several .sclient files at once.
    3. Or select a ZIP archive.
    4. S-Client extracts supported mod and shader-pack files.
    5. Your library syncs to your Google account.

    PRIVATE FIRESTORE LIBRARY

    Each account sees only its own installed mods and custom shader packs. No user-to-user mod sharing is enabled.
