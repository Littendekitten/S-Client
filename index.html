About .sclient

S-Client mods use a small JSON manifest. They can expose supported gameplay options and actions without running arbitrary uploaded JavaScript.

HOW TO INSTALL

  1. Download a .sclient mod.
  2. Choose Import .sclient.
  3. Enable the mod in Installed mods.
  4. Configure its features in the game panel.
